# C++ 인게임 검수 (오너용)

**C++ exe만** 게임에서 켜 보고 표에 `pass` / `fail` 적기. Python은 **안 써도 됨** (에이전트가 코드 비교는 이미 함).

---

## 실행

**F5** → 빌드 후 `Pipela.exe` 실행 (또는 `빌드.bat` / Ctrl+Shift+B 후 `scripts/run_cpp_pipela_dev.bat`)

콘솔에 `C++ workers ON` 나오면 OK.

---
