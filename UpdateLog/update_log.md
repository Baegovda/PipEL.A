## 0.10.x

### 0.10.12 (2026-07-21)

- **설정 카테고리** — 2열 그리드·브레드크럼 제거, 단일 열 목록 + 상단 헤더로 재편.

### 0.10.11 (2026-07-21)

- **UI 정렬** — 제어창·설정·터미널·액션 그리드 등 전반 요소 가로 중앙 정렬.

### 0.10.10 (2026-07-21)

- **터미널 로그** — 일반 콘솔 방식(`QPlainTextEdit`)으로 전면 재작성. 줄 단위 append·자동 스크롤·고정폭 글꼴.

### 0.10.9 (2026-07-21)

- **설정 숫자 입력** — 드래그로 값 변경이 끊기던 문제 수정; 모든 숫자 칸에 통일 적용. Shift·Ctrl로 민감도 조절.

### 0.10.8 (2026-07-21)

- **상단 스트립** — 게임/프로그램 포커스 전환 시 클라 타이틀바가 잠깐 위로 올라오던 Z-order 깜빡임 수정.

### 0.10.7 (2026-07-21)

- **커서 HUD** 아이콘이 마우스를 지연 없이 따라다니도록 개선 (훅 즉시 갱신 + DComp 오프셋만 이동).

### 0.10.6 (2026-07-21)

- **LeftClick** 시전 시 프레임 떨림·해제 클릭이 안 먹히던 문제 수정 (입력 처리·합성 무시 타이밍 정리).

### 0.10.5 (2026-07-21)

- **킬 카운터** 창 높이가 게임 클라이언트보다 커지던 문제 수정 (도크 높이 로직 전면 재작성).

### 0.10.4 (2026-07-21)

- **Call Merc** 버튼에 이름이 안 보이던 문제 수정.

### 0.10.3 (2026-07-21)

- **LeftClick** — 켜자마자 꺼지던 문제 수정 (합성 클릭·홀드 타이밍 분리).
- **RightHold / Flame** — LeftClick 자동 클릭 중 합성 우클릭이 기능을 토글하던 문제 수정.
- **기능 추적 로그** — `%LOCALAPPDATA%\\Pipela\\feature_trace.log` (기본 deep, 전 워커·상태·입력 기록).
- **터미널 로그** — 가독성 개선 (시간·칩·본문 간격, `·` 구분).
- **컨트롤 패널 하단** — 페이즈/해상도 중복 제거 (상단 스트립만), **종료** 버튼만 유지.
- 버튼 텍스트 가운데 정렬, 캡처 UI 개편, Start Game 터미널 로그 등 (상세: `AGENTS.md` §11).

### 0.10.2 (2026-07-21)
- **README** — C++ `Pipela.exe` 기준 사용자 랜딩으로 정리 (Python 레거시는 개발 문서로만 안내).
- 다른 프로젝트용 거버넌스 부트스트랩 프롬프트: `scripts/bootstrap-agent-governance-prompt.md`.
- AI 작업 정책·증분 빌드 워크플로 (`AGENTS.md`, Cursor rules).
- **F5** → 빌드 후 실행 (디버거 없이 `Pipela.exe`).
- **Ctrl+Shift+B** / `빌드.bat` → 변경된 소스만 증분 빌드.
